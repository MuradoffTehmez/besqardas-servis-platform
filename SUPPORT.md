# Dəstək

Bu repository Phase 1 frontend demo və texniki inkişaf üçündür.

## Hansı kanaldan istifadə etməli

- Təkrar yaradıla bilən xəta: [bug report](https://github.com/MuradoffTehmez/besqardas-servis-platform/issues/new?template=bug_report.yml)
- Yeni funksiya və texniki iş: [feature request](https://github.com/MuradoffTehmez/besqardas-servis-platform/issues/new?template=feature.yml)
- Sənədləşmə problemi: [documentation issue](https://github.com/MuradoffTehmez/besqardas-servis-platform/issues/new?template=documentation.yml)
- İstifadə və ümumi sual: [GitHub Discussions](https://github.com/MuradoffTehmez/besqardas-servis-platform/discussions)
- Təhlükəsizlik boşluğu: [SECURITY.md](SECURITY.md) — public issue açmayın

## Hesabata daxil edin

- commit SHA və ya release;
- istifadə olunan tətbiq və route;
- demo rolu/personası;
- əməliyyat sistemi, brauzer və viewport;
- təkrar yaratma addımları;
- gözlənilən və faktiki nəticə;
- şəxsi və məxfi məlumat təmizlənmiş log/screenshot.

Repository issue-ləri production müştəri dəstəyi və təcili servis sifarişi kanalı deyil.
