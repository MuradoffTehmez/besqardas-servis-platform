# Təhlükəsizlik

Bu repo frontend demo mərhələsindədir. Mock API production üçün nəzərdə tutulmayıb; demo şifrələri açıqdır, data yaddaşda saxlanır və server yenidən başlayanda sıfırlanır.

Həssas boşluqları, şəxsi məlumatları və açarları public issue-da paylaşmayın. Repo sahibinə GitHub profilində göstərilən məxfi əlaqə kanalı vasitəsilə bildirin. Private vulnerability reporting aktivdirsə, Security bölməsində “Report a vulnerability” istifadə edin.

Hesabatda təsirlənən commit, təkrar yaratma addımları və təsiri göstərin. Gerçək müştəri məlumatlarından istifadə etməyin.

Production hazırlığına server tərəfində autentifikasiya, RBAC, tenant izolyasiyası, audit, rate limiting və provayder təhlükəsizliyi daxildir; bunlar demo ilə təmin edilmiş sayılmır.
