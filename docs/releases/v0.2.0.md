# v0.2.0 — Çoxrollu Portallar, Əməliyyat Axınları və Resurs İdarəetməsi

`v0.2.0` versiyası **besqardasServis.az** platformasının Frontend və Simulyasiya arxitekturasının tam əhatəli mərhələsini təqdim edir. Bu buraxılışda bütün əsas rollar üçün portallar, əməliyyat modulları, deklarativ CRUD mühərriki və inteqrasiya olunmuş HTTP mock API istifadəyə verilmişdir.

---

## 🚀 Əsas Yeniliklər və İmkanlar

### 1. Çoxrollu Portallar və İxtisaslaşmış Ekranlar
- **Müştəri Şəxsi Kabineti (`/account`)**:
  - Cihazlarım, aktiv və tamamlanmış servis sifarişləri
  - İnteraktiv smeta baxışı, bəndlər üzrə təsdiq və imtina axını
  - Servis statusunun real-vaxt mərhələ xronologiyası (timeline)
  - Ünvanlar, profil məlumatları və bildiriş tənzimləmələri
- **Usta İş Sahəsi (`/technician`)**:
  - Təyin olunmuş və növbədəki tapşırıqlar siyahısı
  - İş qəbulu, diaqnostika qeydləri, material/ehtiyat hissəsi tələbi və istifadəsi
  - Smetanın formalaşdırılması və müştəriyə göndərilməsi
  - Təmir mərhələlərinin status keçidləri və işin təhvili
- **Kuryer Paneli (`/courier`)**:
  - Cihazın ünvandan götürülməsi və ünvana çatdırılması tapşırıqları
  - Çatdırılma statuslarının ardıcıl yenilənməsi
- **B2B Korporativ Kabinet (`/b2b`)**:
  - Şirkət profili, korporativ müqavilələr və filiallar
  - Korporativ xidmət sifarişləri, invoyslar və aktlar
- **Admin & CRM İdarəetmə Paneli (`/admin`)**:
  - Dispetçer təyinatı, usta və kuryer iş yükünün paylanması
  - Sifarişlər, ödənişlər, anbar, filiallar və zəmanət qeydləri

### 2. Deklarativ Resurs və CRUD Mühərriki (`@sp/ui/admin`)
- `ResourcePage` və `ResourceGrid` konfiqurasiya strukturu:
  - Çoxsütunlu cədvəllər, axtarış, status və kateqoriya filtrləri, sıralama və səhifələmə (pagination)
  - Dinamik form modalı (`ResourceEditModal` və `FieldInput`):
    - Mətn, say, valyuta (AZN), tarixlər, seçimlər və çoxlu seçim (`multi`)
    - Çoxdilli i18n sahələr (`I18nInput` — AZ, RU, EN redaktəsi)
  - İcazə və rol əsaslı əməliyyat düymələri (`RowOps`) və audit tarixçəsi

### 3. Autentifikasiya və Təhlükəsizlik
- Telefon nömrəsi ilə OTP daxilolma və təsdiq
- İstifadəçi qeydiyyatı və şifrə bərpası formaları
- Rol əsaslı yönləndirmə (Role-based Routing) və marşrut qoruyucuları (Route Guards)
- İcazəsiz cəhdlər üçün xüsusi xəbərdarlıq və qonaq giriş ssenariləri

### 4. Çoxdillilik (AZ / RU / EN)
- Bütün ictimai səhifələr, kabinetlər, formalar və cədvəllər 3 dildə dəstəklənir
- Bütün status və enum etiketləri (`packages/i18n`) mərkəzləşdirilmiş şəkildə lokalizasiya olunub

### 5. HTTP Mock API və Biznes Simulyatoru (`@sp/mocks`)
- Real Azərbaycan servis kontekstinə uyğun seed məlumatları (brendlər, modellər, xidmətlər, ustalar, filiallar)
- Rollar üzrə 100-dən çox mock endpoint
- Sifariş yaradılması, status keçidləri və istifadəçilər üzrə təcrid olunmuş lokal vəziyyət idarəetməsi
