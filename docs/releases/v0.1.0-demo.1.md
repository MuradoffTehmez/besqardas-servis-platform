Web/admin production build-ləri lokal keçib. Mock API testləri qonaq girişini, servis ID-sini və müştəri sifarişlərinin izolyasiyasını yoxlayır. CI TypeScript, test və build işlədir. Tam brauzer/E2E və mobil qəbul tamamlanana qədər bu release draft saxlanılır.

Mock server yalnız lokal demo üçündür. Real ödəniş və mesaj göndərilmir, məlumatlar restart zamanı sıfırlanır. Demo hesablar və təqdimat ssenarisi `README.md` və `docs/DEMO.md`-dədir.
